# Description модуля (установщик)

Два слоя, не смешивать:

1. **`<description>` в `mod_bsr_form.xml`** — HTML на экране установки/модуля. Сейчас CDATA, русский.
2. **`MOD_BSR_FORM_XML_DESCRIPTION` в `.sys.ini`** — короткий текст в списках расширений (RU и EN).

Инструкции для админки полей — XML `label`/`description` через `.ini`, не копируй туда весь HTML.

## HTML в `<description>`

- Только CDATA. Без `<script>`, `<iframe>`, внешних stylesheet.
- Инлайн-стили допустимы (установщик не грузит CSS модуля).
- Структура блока: заголовок, как открыть форму, редирект, Метрика, зависимость RadicalForm.
- Классы вызова: `bsr-open-modal` и `bsr-open-{form_id}`.
- Ссылки: RadicalForm, без битых URL.
- Не дублируй весь README. 1 экран, списки короткие.

## Когда править

| Изменение | XML description | sys.ini | README |
|---|---|---|---|
| Новая возможность, видимая админу | да, 1 абзац | да, если меняется суть | да, коротко RU+EN |
| Внутренний фикс | нет | нет | нет |
| Смена класса открытия/зависимости | да | да | да |

EN-инструкция также лежит в `MOD_BSR_FORM_INSTRUCTIONS_HTML` (en-GB `.ini`). Если обновляешь HTML — синхронизируй XML и этот ключ или удали ключ как мёртвый. Не держи три разных текста.
